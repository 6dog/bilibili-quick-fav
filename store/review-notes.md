# Chrome Web Store 审核测试说明

## 核心功能

1. 登录 B站并打开任意含普通视频封面的受支持页面。
2. 将鼠标移入视频封面，出现扩展收藏按钮；移到标题、作者或空白区域时不出现。
3. 首次点击按钮，选择一个收藏夹；选择完成后继续原收藏操作。
4. 再次点击只会从该收藏夹取消，不改变其他收藏夹。
5. 打开普通视频详情页，视频默认变为 1.5 倍速；手动切换到 2 倍速后，当前视频不会被改回。
6. 点击 Chrome 工具栏扩展图标，可重新选择收藏夹并关闭或开启默认倍速。

## 测试账号

扩展不需要开发者服务器或专用测试账号。审核人员可使用自己的 B站账号；未登录状态下只会提示先登录，不会产生写入。

## 权限与隐私

- 唯一权限为 `storage`，用于保存快捷收藏夹选择和倍速开关。
- 没有 service worker、远程代码、广告、分析或外部服务器。
- B站 API 请求由页面内容脚本直接发起。
- CSRF 值只在收藏写入前读取一次，不保存、不记录、不发送给第三方。
