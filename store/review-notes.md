# Chrome Web Store 审核测试说明

## 无账号时

在普通 B站视频页可以检查 1.5 倍速及工具栏弹窗；收藏状态请求会提示登录或读取失败，不会提交收藏写入。登录遇到验证码时按 B站页面流程完成，扩展不提供绕过方式。

## 收藏功能

1. 使用审核人员自己的 B站账号登录，并在 B站先建立至少一个收藏夹。扩展没有专用测试账号。
2. 打开普通视频详情页或含普通视频封面的首页。详情按钮位于播放器下方；封面按钮仅在鼠标移入封面时出现。
3. 首次点击收藏按钮，选择一个收藏夹；关闭选择框或按 Escape 不会写入。选定后仅对该收藏夹执行一次加入或移除。
4. 再次点击只更改所选收藏夹，不影响其他收藏夹。测试后可再次点击恢复原状态。
5. 如已选过收藏夹，可点击 Chrome 工具栏扩展图标重新选择。要验证完整首次使用流程，请在隔离测试 Chrome 配置中重新安装扩展并清除该扩展的本机存储。
6. 账号没有收藏夹时会提示先创建；网络或接口失败时保留配置并允许重试，不会盲目提交写入。

## 倍速与权限

普通视频默认 1.5 倍速；手动改速后当前视频保留手动选择。工具栏弹窗可关闭或开启默认倍速，设置在标签页间同步。扩展仅申请 `storage` 权限；内容脚本在四个 B站站点运行，直接请求 B站 API，不使用开发者服务器、广告或分析服务。
